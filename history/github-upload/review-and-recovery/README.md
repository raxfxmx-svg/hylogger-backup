# Backup and Recovery

`14_verify_database_backup.py` records the current release and structure, creates a backup, restores it into a temporary database and compares data, relationships, foreign keys and release state. It then removes the temporary database and records the successful backup pointer.

Merge this group's `etl4/` files into the main tree. It requires migrations, PostgreSQL/PostGIS, pg_dump/pg_restore, appropriate local permissions and the current deployment_asset_manifest.json generated by step 37. Database backups do not contain images, spectra or Parquet assets; preserve those separately using the manifest.
