# HyLogger Visualisation: Early Exploration

AI-generated code and documentation for exploring HyLogger drill core images, mineral intervals, and spectra.

| Item | Purpose |
| --- | --- |
| `web/` | Interactive 3D core viewer, depth chart, spectrum display, and interval review controls. |
| `server/` | FastAPI backend for borehole data, images, spectra, and review annotations. |
| `scripts/` | Local TSG processing and NVCL data download and import tools. |
| `requirements.txt` | Python dependencies. |
| `.gitignore` | Excludes local environments, datasets, databases, caches, and logs. |

Datasets and generated databases are not included. Data must be obtained and imported separately.
